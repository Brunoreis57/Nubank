# Nubank Mobile Replica (High-Fidelity)

A high-fidelity mobile-responsive replica of the Nubank banking application, built with pure HTML, CSS, and Vanilla JavaScript.

## Features
- **Dashboard (Home)**: Complete replica including "Saldo em conta", credit card details, and a functional "Nubank Vida" carousel.
- **Statement (Extrato)**: Dynamic transaction history with search and advanced filtering (Tudo, Entradas, Saídas).
- **Interactivity**: 
    - **Visibility Toggle**: Eye icon to blur/hide sensitive financial data.
    - **Floating Bottom Nav**: Glassmorphic bottom navigation bar with active states.
    - **Live Clock**: Phone status bar with a real-time clock, signal, and battery indicators.
    - **Back Button**: Navigation from Extrato back to Home.
- **Animations**: Subtle entrance animations and screen transitions for a native mobile feel.

## Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (ES6+)
- [Lucide Icons](https://lucide.dev/)

## How to Run
1. Clone the repository.
2. Open `index.html` in any modern web browser or serve it locally using a tool like `npx serve .`.
